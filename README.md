# 홈바 레지스트리

`홈바_마스터_가이드_V54.xlsx`에서 생성한 단일 파일 웹앱. 빌드 도구·서버·계정 없이 파일 하나로 동작한다.

## 올리는 법

1. github.com에서 New repository → 이름 입력 → **Public** → Create
2. `uploading an existing file` → `index.html`을 드래그 → Commit changes
3. Settings → Pages → Branch를 `main`으로 변경 → Save
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 접속

수정할 때는 같은 이름으로 다시 드래그하면 덮어쓴다.

## 판정 규칙

- **정규** — 필수 재료를 전부 보유하고 대체 표기가 없음
- **근사** — 필수 재료를 전부 보유하지만 대체품으로 조주
- **불가** — 필수 재료 중 미보유가 있음

`(선택)` 표기된 재료는 판정에서 제외한다. 엑셀 판정 규칙 시트(V52)와 동일한 논리다.

## 지인과 쓰는 법

재고 탭의 **전부 해제** → 자기가 가진 재료만 체크 → **링크 복사**.
그 주소를 열면 체크 상태가 그대로 재현된다. 재고는 각자 브라우저에만 저장되며 서버로 가지 않는다.

## V54 원본에서 고친 것

1. **블랙 러시안** — 재료가 `커피 리큐르 [없음]`으로 되어 있으나 깔루아를 보유 중이다. 깔루아는 커피 리큐르이므로 미보유 표기가 잘못됐다. 막힘을 제거해 정규로 전환했다. 정규 104 → 105.
2. **플랜터즈 펀치** — `사탕수수 주스/시럽`의 슬래시가 재료 구분자로 파싱되어 한 재료가 둘로 쪼개졌다. V52 데이터 규약(괄호 안 슬래시만 예외)을 벗어난 표기다. `사탕수수 주스 또는 시럽` 단일 재료로 통합했다.

두 건 모두 엑셀 원본에도 남아 있으므로 다음 버전에서 반영하는 편이 낫다.
